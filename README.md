DealHawk is a static Black Friday and Cyber Monday deal finder: 19 deals its maker's agent found and checked on 2026-11-27, each with its product, store, store link, sale price, usual price, discount, the moment its price was checked and the source it was read from — with working search and filters by category, store and discount, and an honest verdict per deal (new low, strong price, routine sale or inflated discount) that says what kind of deal it really is.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
node serve.ts --port 8080
```
